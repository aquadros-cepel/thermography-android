## Thermal Inspection Application – Pilot Release

Application Name: Thermal Energy
Version: v0.1.0 – Pilot Release

Target Device: FLIR i65
Build Type: Beta / Validation Release
Application Type: Thermal Inspection & Predictive Maintenance

# 1. Purpose of this Release

This is the first pilot release of the application developed for validation and testing on the FLIR ACE platform.

The primary goal of this release is to validate:
- ACE platform compatibility
- Thermal camera integration
- Thermal image acquisition
- Temperature measurement workflow
- Risk assessment calculation
- Offline-first data persistence
- Cloud synchronization
- User experience and application stability

# 2. Application Overview

The application supports industrial thermal inspections and predictive maintenance workflows.

Capabilities:
- Execute inspection routes
- Capture thermal and visual images
- Perform thermal anomaly assessment
- Calculate Delta Temperature (ΔT)
- Register inspection findings
- Operate fully offline
- Synchronize with cloud infrastructure

# 6. Inspection Routes Workflow

Select Route → Equipment Groups → Equipment Subgroups → Equipment -> click in câmera icon

Thermographic Registration includes:
- Equipment data (Instalation, equipment location, equipment, inspection route, report number, service order)
- Object thermogram selection (Termograma de Monitoramento)
- Reference thermogram selection (Termograma de Referência)
- Meta data from object thermogram and delta T
- Visual image selection (Imagem Visível)
- Component selection (Componente)
- Delta Temperature calculation 
- Risk assessment (Condição) -> Normal, Baixo Risco, Médio risco, Alto risco, Alto Risco iminente (Low risk, medium risk, high risk, imminent high risk)
- Analysis Description (Descrição da Análise)
- Maintenance recommendation (Recomendações)
